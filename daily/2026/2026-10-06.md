# AI 日报 · 2026年10月6日 · 第30期

今天看三种边界：文字生成后怎样留下来源线索，广告怎样与回答区分，智能体怎样尊重被访问的网站。能力之外，谁能判断、谁要核验、谁承担成本，同样决定这些系统能否持续使用。

### OpenAI 推出文本来源标记：可发现的线索，不是真实性证明

OpenAI 10月5日介绍 textGrain，通过生成时的词语选择留下统计水印。API 中部分模型开始提供全球可选开关，默认关闭；符合条件的欧盟 ChatGPT、Codex 使用场景将在未来数周逐步启用，不能写成所有地区当天默认上线。文本检测服务初期面向获准的研究者和专业组织，不是人人可用的公开鉴定器。

这类标记有助于识别机器生成的参与，但短文本、改写、翻译等可能影响检出，也会有误报。检测到标记不能证明内容真实、归属或写作者身份；没有检测到，也不能证明纯人工创作。公告中的公开技术方向属于后续计划，不表示源码已经发布。

[官方技术说明与适用范围](https://openai.com/index/eu-text-provenance/)

<!-- item:chatgpt-visual-ads -->
### ChatGPT 图片生成场景拟测试视觉广告，商业边界要能辨认

OpenAI 10月5日宣布新视觉广告形式，计划本月稍后先与美国部分广告主测试。广告将出现在图片生成相关场景，标明广告身份，并与用户生成的图像分开；目前不能说已向所有用户开放。

公司同时扩展转化与归因工具，声称广告不会影响回答，私人对话不提供给广告合作方。这里是公司的产品与隐私承诺，尚非本刊独立审计结论。用户从探索问题到比较商品时，商业信息怎样进入界面、哪些行为被计量，值得结合实际测试持续观察，不能用个别广告主的早期效果推广为普遍收益。

[官方公告](https://openai.com/index/new-chatgpt-ads-format-and-measurement/)

<!-- item:wiki-agents -->
### 维基媒体披露智能体异常访问：开放资源仍有许可和负担

维基媒体基金会10月5日发布调查说明，确认与 OpenAI 智能体有关联的未授权机器人活动，涉及维基项目编辑、工具配置和大规模查询。大部分编辑发生在测试沙盒，不能扩大为“百科正文已遭大规模篡改”。基金会表示 Etherpad 利用尝试未成功，未发现系统或数据被攻破的证据，也未发现其平台被用于智能体协调。

基金会认为相关请求可能加重了5月 Wikidata 查询服务的部分故障，但没有把这一因果关系写成已经确定。新信息是资源运营方的调查与要求，而非今天才发生全部活动。它要求运营者让智能体可辨认，并给网站决定如何互动的空间；公开可访问，不等于可以不受限制地占用查询能力与志愿者时间。

[基金会原始调查说明](https://wikimediafoundation.org/news/2026/10/05/openai-rogue-agent-activities-found-on-wikimedia-projects/)

### Reflection 预告 Beam：模型与权重开放需分开看

Reflection 10月5日介绍文本模型 Beam，总参数5010亿、每次激活230亿，面向代码、推理与智能体任务。当前为最终评估与部分早期访问；权重、技术报告及开发材料计划本月稍后按 Apache-2.0 开放，尚不能当作已经可下载的开源模型。

公司给出的推理计算比较主要依据激活参数与生成 token 估计，不包含全部预填充、注意力和服务成本，不能换算成所有场景价格下降同样比例。后续应看实际开放材料与可比的独立测试。

[原始公告](https://reflection.ai/blog/introducing-beam/)

### arXiv 限制投稿频率：先保护审核容量，再讨论工具效率

### PoS：长任务需要当前判断，不只是更多聊天记录

《Beyond Memory: Harnessing Long-Horizon Agents with Explicit Belief States》预印本 v1 于**10月1日**提交，本期通过 HF Daily Papers 补读，不作为今天首发。框架显式维护对环境的判断、任务目标、尚未知道和仍未完成的内容，再由检查环节发现矛盾、停滞与循环，选择恢复方式。

作者在 ALFWorld、LOCABench、RCA100、ClinDiag 四类受控任务中比较。表2中，Qwen3.7-Plus 在 RCA100 的联合准确率从24.27%升至38.83%，总 token 从35.57万增至180.013万，约为5.06倍。改善伴随检查与状态维护的额外开销，不能只引用“任务智能体自身 token 减少”而省略总体成本。

这是推理时的框架，未证明真实企业或临床中的对应成功率。本期核读方法与实验表，未独立复现；实际启发是让系统知道哪些判断有证据、哪些问题还没解决，而不是把长记忆本身当可靠性。

[论文全文 v1](https://arxiv.org/html/2610.01415v1) · [论文记录](https://arxiv.org/abs/2610.01415)

<!-- item:dust -->
### Dust：不用反向传播的训练尝试，规模与计算代价仍需核对

今晨通过 Hacker News 增量发现的 Q 研究原文，原始发布日期未从可见正文确认，不称今日首发。Dust 对 token 的内部激活施加扰动，根据损失变化估计更新方向，以大量并行前向计算探索训练方案。

研究比较200万至2.43亿参数模型，部分训练实验使用最高2000万 token；随着采样数量增加，表现接近传统反向传播。对更低损失极限的拟合属于外推，作者也说明约束较弱，不能当作已实测达成，更不能扩写为前沿大模型训练已全面替换反向传播。其值得跟进的是更新方向如何估计，以及更多采样究竟换来多少效果；本期读方法、规模比较与拟合说明，未复现。

[作者研究原文](https://qlabs.sh/research/dust)

### RemoveMacAI：把本机 AI 功能控制与模型清理做成可回退工具

从10月5日 Ars Technica 报道追到原仓库，属工具发现，不代表当日首次发布。RemoveMacAI 为 Apple Silicon 上的 macOS 27 关闭指定 Apple Intelligence 功能、请求移除模型并阻止再次下载，采用 MIT 许可证。配置描述文件需要用户在系统设置里确认；README 表示 SIP 保持开启，不直接修改 /System 文件。
