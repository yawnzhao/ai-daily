## 今日重点

<!-- item:eternal -->
### 《永恒互补》：天才机器或许最该干「无聊」的活

OpenAI 于10月1日在 Intelligence Age 平台发布 Hemanth Asirvatham 与 Elliott Mokski 的随笔《The eternal complement》。作者声明这是「下一经济」系列首篇，代表个人观点，不等于 OpenAI 机构立场。本刊核读官网正文。

文章把前沿智力与落地能力写成经济学意义上的互补品：更好的问题抬高望远镜的价值，更好的仪器也抬高好问题的价值。作者勾勒两条路径——「深度文明」用推理与高效仪器在有限扩张下推进；「广度文明」则因自然复杂度，必须靠越来越庞大的实验、制度与执行链把想法变成现实。文中用伽利略望远镜与詹姆斯·韦伯望远镜的对照说明：看得更远，往往不只需要更聪明的头脑，还需要更大的「官僚与后勤」。本刊观察：在模型能力新闻密集的一周后，这篇把焦点从「谁更聪明」挪到「谁能把想法做完」。

### 巴克莱扩大用 Claude：代码、邮件与客服同一套企业标准

Anthropic 于10月1日宣布，英国全能银行巴克莱扩大与 Anthropic 的战略协作，在全球业务中推进企业级 Claude。发布文称，巴克莱预计到2026年底 Claude Code 采用率达开发者群体的50%，并在2027年覆盖多数软件工程师。文中还写：逾16,000名同事已使用助手、累计逾百万次检索；邮件平台日处理约120,000封。上述数字均来自官方通稿中的 Paul Smith（Anthropic CCO）与 Craig Bright（巴克莱集团联席 COO）表述，本刊未独立审计。

新闻强调在强监管机构落地所需的安全与治理，而不是新模型发售。与上期「政府侧正式可用」相比，这是金融业规模化的企业案例。

<!-- item:safety-cases -->
### 训练也要写「安全案例」：OpenAI 公开初稿指南

OpenAI 于9月28日发布《Towards safety cases for frontier AI training》（本期按原始日期补读）。公司称，进入任何前沿强化学习训练运行之前，应有结构化安全文档；理想形态是其他高风险行业所用的「安全案例」——全面、结构化、基于证据的风险论证。文中承认 AI 因能力涌现，难以立刻达到航空或核电同等严谨度，故把安全案例当作正在逼近的北极星，并邀请外部反馈。

指南把技术栈拆成对齐训练、遏制与监测三层，并另列操作规范与失调事件调查。范围明确限于前沿 RL 训练，部署侧需另论。可与上期白宫自愿承诺、蒸馏调查对照：一边是对外自愿文本，一边是厂商把「继续训练前要写什么」摊开。

<!-- item:mods -->
### Claude Code mods：用 TypeScript 改自己的编程代理

Anthropic 于10月1日在 Claude 博客介绍 mods：小型 TypeScript 函数，可改写提示、加 UI、替换内置能力或扩展新功能；可随插件分发，适用于 CLI 与桌面端。官方写明 mods 拥有与 Claude Code 相同的本机访问权限、**无沙箱**，只应安装可信来源——与装任意本地代码同等谨慎。动机是：Hooks 不够改事件、画 UI 或替换功能，开发者不想事事等官方发版。设计曾先在 GitHub 公开征求意见。

## 论文速递

<!-- item:mid-harness -->
### Mid-Harness：在「模型」和「执行器」中间再花算力核对动作

论文 arXiv:2609.39982 于发现窗口内公开。已核 arXiv HTML 摘要与正文主要结果叙述，未复现；预印本。

作者提出 Mid-Harness：在终端代理每一步，先从同一历史采样多个候选动作，经校验器挑选后再交给不变的 harness 执行。用 TMAX-9B 作生成器时，作者报告：弱校验下加大采样收益有限；用 GPT-5.6 Sol 作校验器、采样宽度 8 时，TerminalBench-Lite 上 Pass@1 从基线 50.00% 提到 68.03%。自校验设定下，成对比较优于列表式/逐点式；把更强校验器的成对回答蒸馏回 TMAX-9B，还可在不改生成器的情况下继续抬升。作者还报告动作级缩放可与 Best-of-T、顺序精炼等轨迹级方法组合，并在若干模型与基准上迁移。

局限：缺少「金标动作」标签，难以直接度量校验正确率；主要结论依赖特定基准与模型。它与上期「计划声明—执行差距」同属代理可靠性：这次问的是执行前要不要多花算力挑动作。
