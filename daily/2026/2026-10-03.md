## 今日重点

<!-- item:frontier-academy -->
### Claude Frontier Academy：1 亿美元，要培养 1 万名能把模型装进业务的工程师

Anthropic 新闻室列出日期为 **10月2日** 的公告（页面 meta `article:published_time` 为 2026-10-02T23:01:00.000Z；采集时全文已可打开）。公司启动 Claude Frontier Academy，承诺投入 **1 亿美元**，目标到 **2027 年底** 培养 10,000 名 Frontier Deployed Engineers（FDE）。首期合作方包括 Accenture、Bain、Capgemini、澳洲联邦银行、Deloitte、McKinsey、Morgan Stanley、Novo Nordisk 等。

培训按“住院医师”式路径：多日面授与模拟企业部署，通过后进入约 12 周驻场；组织提名工程师并携带回公司要落地的 Claude 项目。地点包括旧金山、纽约与伦敦。**1 万是培训目标，不是已结业人数；1 亿美元是公司承诺口径，本刊未独立审计拨款进度。**本刊观察：企业缺口往往不在“有没有模型”，而在有没有人能把模型接到安全审查、流程与交接上。

<!-- item:suncatcher -->
### Project Suncatcher 原型卫星已入轨：太空算力仍是长期试验

Google Research **10月1日**宣布，与 Planet 合作的 Project Suncatcher 原型卫星已随 SpaceX Transporter-18 搭载入轨，团队确认卫星联系正常并按预期运行。这是探索未来是否可能在太空部署可扩展机器学习基础设施的长期研究步骤之一；随后数周将收集 TPU 在轨承受辐射与热环境的数据。同行评议论文已发表于 *Joule*。

本刊核读官方全文。**入轨不等于太空数据中心已可用，也不等于算力经济结论已经成立。**它提供的是硬件环境试验，而不是生产负载承诺。

<!-- item:gpt6-guide -->
### GPT-6 族选用指南：先匹配工作负载，再谈推理强度与成本

OpenAI **10月2日**发布《A model guide for the GPT-6 family》，面向把 GPT-6 系列用于原型、功能开发与多步工作流的团队。指南强调：用缓存与压缩控制上下文和成本（文中称缓存输入 token 最高可便宜约 95%，**为厂商报价口径，非本刊实测**）；按任务选择模型、reasoning effort 与速度；保持提示、skills 与仓库说明一致；对长任务使用 steering、异步工具与委托，并事先规定何时必须请示人类。

这是产品文档式实践建议，不是新模型发布。本刊关联：它把“模型有多强”换成“如何在生产里选、控、盯”，与昨日关于执行能力的讨论同一条线。

<!-- item:dgx-spark-64 -->
### DGX Spark 64GB：本地 agent 的入门配置，厂商给出集群加速数字

NVIDIA **10月2日**介绍 DGX Spark 新增 **64GB** 统一内存配置，由 Acer、ASUS、Dell、Gigabyte、HP、MSI 等厂商提供，沿用 GB10 Grace Blackwell、DGX OS 与 NVIDIA AI 软件栈，文称可支持最高约 1000 亿参数量级本地模型（**厂商能力声明，未独立实测**）。两台 64GB 可通过 Sync Cluster Assistant 组集群；NVIDIA 给出的 Qwen 3.8 27B 测试称双机相对单机最高约 **1.7×** 性能。预装 Agent Toolkit、Nemotron、Ollama、vLLM、PyTorch CUDA 等。

本刊核读官方博文，**不把厂商基准当作可迁移的端到端结论**。对本期主题而言，它提醒：本地私有推理与云上租用正在同时扩容，选择取决于数据边界和利用率，而不是单一峰值。

### Keyword Harnesses Fail Open：宽松的工具调用分数，可能在给从未调用工具的模型打高分

预印本 arXiv:2610.02142v1，**10月1日**提交。作者在一对共享解码器/词表的西班牙语安全向小模型上记录假阳性：约 **661.6M**（代码/技术文本占比高、无专用 SFT）与约 **1,109M**（网页为主、含约 6B token 工具 SFT）在宽松工具指标 B4 上几乎同分（**0.660 vs 0.650**），但 verbatim 复现训练样例的工具调用时，600M 为 **6/6**，1B 多检查点为 **0/6**。首 token 探测把 1B 失败定位到对 `<|tool_call|>` 先验被网页训练阶段冲掉（概率约 \(10^{-4}\)–\(10^{-5}\)）。文中提出一套便宜的严格诊断阶梯，并给出定向 SFT 修复路径。

本刊核读摘要、HTML 结果表与局限段，**未复现**。不能外推到所有工具评测；它说明的是：匹配关键词的 harness 可能“默认放行”。与本期 RLM / 生产指南并列阅读时，重点是评测是否真的在测工具行为。

### AstaBrief：把“带引用的科研报告”做成可自托管的小模型

Ai2 **10月2日**在 Hugging Face 介绍并开源 AstaBrief 8B：输入研究问题与检索到的文献片段，一次性生成带引用报告；在 Asta 平台作为 Fast mode，与 Claude 驱动的 Thinking mode 并列。训练强调引用过滤与偏好数据；文称相对原先分段生成管线有近一个数量级的效率提升（**作者报告，未独立实测**）。开放权重便于机构在敏感课题上本地运行，并附示例工作流。

已核官方博文；许可证与具体权重卡以仓库页为准，本刊未部署。观察：开源的价值不只是省 API 费，还有证据链与部署边界由使用者控制。
