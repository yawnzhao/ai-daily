# AI 日报 · 2026年10月7日 · 第31期

智能体走进网站、办公文件和安全系统之后，能力之外还有一个实际问题：它代表谁、能改什么、怎样知道任务做对了？今天从个人智能体协议谈起，连到安全权限、新模型和专业工作评估，再用两段话语场材料拆开其中的工程问题。

### 个人智能体协议：用户授权之外，企业也要能决定怎样接入

**原标题：** Introducing Personal Agent Protocol

Sierra 与 Meta 10月6日宣布共同开发 Personal Agent Protocol，参与方包括 Walmart、Stripe、Shopify 等。方案让个人智能体表明代表的用户，以 OAuth 建立授权会话；用户决定只读或写入权限，企业决定提供网页、API 或自家智能体等接入方式。查询库存与修改订单可以有不同的授权要求。

**v0.1 规范计划本月稍后发布**，参考实现和更细权限、支付扩展仍在后续路线中，不能写成成熟协议已普遍部署。TechCrunch 当天采访还显示，不同网站的限制原因并不相同：Walmart 否认刻意阻挡个人智能体，将部分中断归于验证流程。这次协议倡议的新意，是把用户意图、访问方身份和接收方规则放到同一会话里；它不意味着智能体从此可以任意访问所有网站。

[Sierra 原始公告](https://sierra.ai/blog/introducing-personal-agent-protocol) · [TechCrunch 原创采访](https://techcrunch.com/2026/10/06/the-next-hurdle-for-ai-agents-getting-websites-to-let-them-in/)

### Anthropic 扩大安全验证计划，按任务与身份分级开放

**原标题：** Expanding the Cyber Verification Program

Anthropic 10月6日扩展 Cyber Verification Program。防御级面向监测、响应、恶意软件分析和维护系统中的漏洞验证；红队级针对获授权的机构渗透测试，个人不能申请这一档；更高的专项级只对少数经核实的组织开放。模型拒绝边界放宽，不等于授权任意攻击或取消全部防护。

公司在自设的10个场景、每档各50次尝试中比较权限设置，显示放宽限制能让更多合法测试继续，但这不是外部审计或普遍安全保证。验证计划要求保留数据以监测滥用；更强调隐私的 Enterprise Foundational Safeguards 预计稍后推出，不能笼统写成现在所有申请者均可零留存。实际部署要分清身份审核、任务授权、模型限制与数据安排。

[官方计划及评估说明](https://www.anthropic.com/news/cyber-verification-program)

### Mistral Large 4 开始 API 预览，权重开放仍是月底计划

**原标题：** Introducing Mistral Large 4

Mistral 10月6日发布 Large 4 预览：原生多模态混合专家模型，总参数1万亿、每次激活490亿，面向推理、代码与智能体工作。**当前可通过 Mistral Studio API 使用，权重、架构报告和训练说明计划月底开放**；不能把预览发布等同于已可下载权重。

公司强调减少对合法安全研究的误拒，当前较少限制的网络安全模式面向经过审核的伙伴。公告给出多项公司评估成绩，但未据此证明模型在任意实际任务中的安全或成功率。本期关注部署选择与开放日程；后续需要结合真正发布的权重、许可、技术材料和可比评估，再判断自部署条件与代价。

[模型原始公告](https://mistral.ai/news/mistral-large-4/)

### OpenAI 与 Ironclad 把合同流程变成任务：评分提高不等于合同自动完成

**原标题：** Advancing computer use with Ironclad

10月6日官方研究案例把合同审批、采购流程和可复用法律条款配置拆成11项任务，每项有8至50条评分标准。GPT-6 Astra 的平均标准得分为55.0%，GPT-5.6 Sol 为41.6%；这是满足要求的平均评分，**不是完整任务成功率**。

两者估计单次用时从37.0分钟降至19.2分钟，但时间依据假定处理速度模拟，不是客户实测省时。Astra 使用 Max、Sol 使用 High 推理设置，结果只覆盖这11项研究任务。训练与评估使用筛过个人信息的公开 SEC 合同衍生模拟任务，未使用非公开客户合同。值得关注的是把金额门槛、审批例外和最终流程一起检查，而不是从一个演示推断全部专业工作已能无人接手。

[官方方法、结果和脚注](https://openai.com/index/advancing-computer-use-with-ironclad/)

### HyperBrowseComp：获准上网之后，仍要找到真正支持答案的证据

**原标题：** HyperBrowseComp: A Multilingual and Multimodal Stress Test for Web-Browsing Agents

《HyperBrowseComp: A Multilingual and Multimodal Stress Test for Web-Browsing Agents》v1 **10月2日**提交，本期因10月6日 HF Daily Papers 上榜补读。基准包含423道人工撰写、复核的题目，覆盖13种语言，要求找到简短、可核实的答案；有些线索在视频、图片或扫描文档里，不只是网页文字。

研究先排除无需上网也容易答出的题目，再比较模型与原生搜索、Exa 或 OWL 等工具组合。报告的最高准确率为31.68%；五个原生搜索配置均未答对的题目约占57.68%。这些结果属于刻意挑选的难题和特定工具组合，**不能换算成日常搜索失败率或全行业排名**。

题目语言间难度不等，真实网页、排序和访问条件也会变化。今天谈接入协议与授权，本论文提醒：能进入网站，和能找到、理解并核对证据，是不同的能力。本期核读设计、采样、实验表与局限，未复现。

### EmbeddingGemma 2：本机检索把文字、画面和声音放进同一空间

**原标题：** EmbeddingGemma 2: an open, lightweight multimodal embedding model

Google 10月6日发布 EmbeddingGemma 2，模型卡列明 Apache-2.0 许可，总参数7.4亿，由文字、视觉和音频模块组成，可按需要加载。模型把不同模态映射到共同向量空间，服务检索、分类与聚类，**不是一款直接生成答案的聊天模型**。

输出向量可从768维缩至128维，减少的是向量存储，而非承诺整个应用内存同步缩小六倍。官方示例中的移动端内存数字有指定设备与量化条件，实际部署仍需测量。它给本机跨模态检索提供可用权重与模型卡；能把文件留在本机处理，与应用其他环节是否联网仍应分开检查。

[Google 原始公告](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/) · [权重与模型卡](https://huggingface.co/google/embeddinggemma-2)
