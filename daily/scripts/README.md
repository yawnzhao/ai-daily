# 口播稿

一期一个文件，文件名即日期，和 `daily/YYYY/YYYY-MM-DD.md` 一一对应。这里是**念出来的那一版**，音频以它为准。

写稿前必读 [口播写作与证据表达规则](STYLE.md)。整期结构、故事与幽默、证据表达、更正和编辑自检统一维护在 STYLE；本文件只维护文件、长度、读法和语音制作约定。

## 文件与制作输入

`daily/YYYY/*.md` 是文字成稿，`daily/scripts/YYYY-MM-DD.txt` 是对应的口播制作输入。两端内容对应与写法按 STYLE 执行；口播改写不覆盖原始标题、型号和来源记录。

## 最小读法表

先确认完整型号和单位含义，再为口播转换；下表示例只说明读法，不是当期新闻数据。不同模型或不同版本不因为同一期出现就合并，阿拉伯数字残留本身不等于错误。

| 类型 | 口播约定 |
|---|---|
| 模型名称、版本 | 保留品牌和型号边界；版本 `5.6` 可写“五点六”。多段版本按原分段读，`2.10` 可写“二点一零”，不省成“二点一”。不能把 `Model-3-8B` 误读为版本“三点八”；先查原型号。 |
| 参数量 | 确认为参数量后，正文叙述优先用亿：`8B` 为“八十亿参数”，`27B` 为“二百七十亿参数”。模型名中的后缀可先保留，首次顺带说明规模，不把参数量改成版本号。 |
| 内存、存储 | `64 GB` 可读“六十四 GB”，同一期保持一致，首次说明是内存还是存储；不笼统写“六十四 G”。GB、GiB、Gb 及每秒速率不可互换；缩写读不清先短试听，不擅自改单位。 |
| 百分比与变化 | `0.5%` 读“百分之零点五”；区分百分比、百分点和倍数。“达到原来的两倍”与“增加两倍”含义不同，先确认基线再改写。 |
| 年份、日期、期号 | 年份逐位读，如“二零二六年”；月日和期号按通常中文数量读。刊期取北京时间，来源事件日期保留实际时区语境。 |
| 时刻、时长、时间戳 | `07:50` 读“早上七点五十分”，时长 `01:30` 读“一分三十秒”；先区分时刻与时长。节目定位时间戳默认留在网页，必要时口播才读。 |
| 范围、小数、缩写 | `5–10%` 读“百分之五到百分之十”；小数位按实际精度读，不自行舍去有效信息。英文缩写保留大小写和词界，不用错误同音汉字代替。 |

## TTS 与停顿

- `<#1#>` 是一秒停顿标记；沿用现有合成链路支持的 `<#n#>` 写法，不计入正文字数。开场结束、话题切换、关键数字前后可按需加停顿；先利用标点和自然断句，不设每板块或每期的数量下限，不连续堆叠来凑时长。试听后调整，不能把标记数量当成语音质量。
- 多音词由 `config/tts-pronunciation.json` 统一注音，使用 `scripts/synth_audio.py` 或在既有请求中传入相同 `pronunciation_dict`。校验、校对、校准、校听的“校”读 jiào（jiao4）；不全局替换“校”，避免影响学校、校园等词。可读口播稿仍保留正常汉字，不能写成“教验/教对”。
- 新增发音修正先用原段短试听确认，接口成功不等于发音已通过听审。已发布节目仅在用户要求时重生成指定范围，试听不自动替换已发布音频。

## 长度

目标 10～13 分钟。moss 音色在语速 1.0 下实测 **5.5～5.8 字/秒**，所以正文 **3,400～4,300 字**；
3,616 字出来是 10:47，3,860 字是 11:47。凭感觉写会严重偏短，2,447 字只有 7:22。

合成参数、接口调用和上传后的回填步骤，见 `audio/README.md`（那个目录不进库）。
