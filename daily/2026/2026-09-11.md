# 日报 · 2026-09-11

## 今日重点

1. **OpenAI 产品日四连发：Agents API 公开测试、GPT-Live-1 全双工语音进 API、ChatGPT for Financial Services、数据产品**。Agents API 把与 Codex / ChatGPT for Work 同源的 Agent 框架开放给开发者，支持任务、模型、工具与运行环境配置；GPT-Live-1 支持同步听说、打断与背景噪声处理；另有面向金融行业的 ChatGPT 版本与「让数据人人可用」的新产品。为什么值得看：Agent 从 OpenAI 的产品变成它的平台——把内部基础设施开放收费，是平台公司的标准打法。一手链接：https://openai.com/zh-Hans-CN/news/product-releases/（已核实）
2. **Anthropic 发布 2026 年 9 月威胁情报报告：8 个月识别并阻断 7 类恶意使用 Claude 案例**，覆盖网络攻击、影响力行动、监控、诈骗、生物滥用、常规武器与非法蒸馏（2025-12 至 2026-08）。最值得注意的案例 GTG-20006：疑似俄罗斯间谍组织用 AI 工作流自动化整个攻击链——恶意软件被安全产品检出后，AI 代理自主修改并重建工具直到免杀；20+ 组织被列入攻击规划。为什么值得看：报告的原话是「AI 把成本反转到了防御方头上」。一手链接：https://www.anthropic.com/threat-intelligence-report-september-2026（已核实）
3. **美国商务部解除对 Claude Fable 5 / Mythos 5 的出口管制**。6 月中旬因越狱风险（可被用于发现并利用代码漏洞）暂停，Anthropic 当时称「狭窄的潜在越狱不应叫停一个数百万人使用的模型」；管制解除后公司宣布恢复全球访问。为什么值得看：与昨日商务部回应蒸馏公告同读——出口管制正在从「一刀切禁令」转向「个案评估」，安全评估与商业利益的平衡点在移动。来源：https://www.quanta.report/story/US_Removes_Export_Ban_on_Anthropic_s_Advanced_AI_Models_as_Security_Concerns_Resolve（转载 BBC，已核实）
4. **OpenAI 被曝考虑放缓前沿研发，并询问国会「行业协调降速是否合法」**。据报道 CEO Altman 在全员会上称希望与其他实验室协调行动放缓步伐，但未必所有同行愿意跟进；公司同时担忧类似安排触犯反垄断法。为什么值得看：从单方面冲刺到试探「集体降速」，前沿竞赛的博弈结构可能正在变化——但这是媒体转述，未获官方确认。来源：http://m.toutiao.com/group/7684245489323213331/、https://www.aichatdaily.com/ai-security/openai-asks-congress-if-industry-wide-ai-slowdown-legal（均为媒体转述）
