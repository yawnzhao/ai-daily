Claude Frontier Academy：1 亿美元，要培养 1 万名能把模型装进业务的工程师

Anthropic 新闻室列出日期为 10月2日 的公告（页面 meta `article:published_time` 为 2026-10-02T23:01:00.000Z；采集时全文已可打开）。公司启动 Claude Frontier Academy，承诺投入 1 亿美元，目标到 2027 年底 培养 10,000 名 Frontier Deployed Engineers（FDE）。首期合作方包括 Accenture、Bain、Capgemini、澳洲联邦银行、Deloitte、McKinsey、Morgan Stanley、Novo Nordisk 等。

培训按“住院医师”式路径：多日面授与模拟企业部署，通过后进入约 12 周驻场；组织提名工程师并携带回公司要落地的 Claude 项目。地点包括旧金山、纽约与伦敦。1 万是培训目标，不是已结业人数；1 亿美元是公司承诺口径，本刊未独立审计拨款进度。本刊观察：企业缺口往往不在“有没有模型”，而在有没有人能把模型接到安全审查、流程与交接上。

来源：Anthropic · 2026-10-02 · 官方公告全文；1亿美元与1万人为承诺/目标口径，未独立审计
算力试验

Project Suncatcher 原型卫星已入轨：太空算力仍是长期试验

Google Research 10月1日宣布，与 Planet 合作的 Project Suncatcher 原型卫星已随 SpaceX Transporter-18 搭载入轨，团队确认卫星联系正常并按预期运行。这是探索未来是否可能在太空部署可扩展机器学习基础设施的长期研究步骤之一；随后数周将收集 TPU 在轨承受辐射与热环境的数据。同行评议论文已发表于 *Joule*。

本刊核读官方全文。入轨不等于太空数据中心已可用，也不等于算力经济结论已经成立。它提供的是硬件环境试验，而不是生产负载承诺。

来源：Google Research · 2026-10-01 · 官方全文；入轨不等于可用太空算力
生产实践

GPT-6 族选用指南：先匹配工作负载，再谈推理强度与成本

OpenAI 10月2日发布《A model guide for the GPT-6 family》，面向把 GPT-6 系列用于原型、功能开发与多步工作流的团队。指南强调：用缓存与压缩控制上下文和成本（文中称缓存输入 token 最高可便宜约 95%，为厂商报价口径，非本刊实测）；按任务选择模型、reasoning effort 与速度；保持提示、skills 与仓库说明一致；对长任务使用 steering、异步工具与委托，并事先规定何时必须请示人类。

这是产品文档式实践建议，不是新模型发布。本刊关联：它把“模型有多强”换成“如何在生产里选、控、盯”，与昨日关于执行能力的讨论同一条线。

来源：OpenAI · 2026-10-02 · 官方指南全文；成本数字为厂商口径，未实测
本地算力

DGX Spark 64GB：本地 agent 的入门配置，厂商给出集群加速数字

NVIDIA 10月2日介绍 DGX Spark 新增 64GB 统一内存配置，由 Acer、ASUS、Dell、Gigabyte、HP、MSI 等厂商提供，沿用 GB10 Grace Blackwell、DGX OS 与 NVIDIA AI 软件栈，文称可支持最高约 1000 亿参数量级本地模型（厂商能力声明，未独立实测）。两台 64GB 可通过 Sync Cluster Assistant 组集群；NVIDIA 给出的 Qwen 3.8 27B 测试称双机相对单机最高约 1.7× 性能。预装 Agent Toolkit、Nemotron、Ollama、vLLM、PyTorch CUDA 等。

本刊核读官方博文，不把厂商基准当作可迁移的端到端结论。对本期主题而言，它提醒：本地私有推理与云上租用正在同时扩容，选择取决于数据边界和利用率，而不是单一峰值。

来源：NVIDIA Blog · 2026-10-02 · 厂商全文；参数量与1.7×为厂商测试口径，未独立实测

话语场精选｜Alex Zhang：脚手架可能比再堆一层模型参数更值钱

人物背景｜ Alex Zhang 是 MIT 博士生，工作横跨 GPU 内核与 KernelBench、Recursive Language Models（RLM）等多 agent / harness 方向。本刊依据 Latent Space 节目介绍与其公开学术主页叙述核验身份，将其观点读作研究者对“系统层能力”的观察，而非实验室官方路线图。（[节目页](https://www.latent.space/p/rlm)）

节目背景｜ Latent Space 是面向 AI 工程师的技术播客与社区，关注工程、产品与研究交界，提供音视频访谈及文字说明。这是节目整体定位，不单指本集。（[官方介绍](https://www.latent.space/about)）

原节目页标注 10月2日。本期核读官方文字稿中的主题提纲与导语：讨论 RLM 的上下文卸载、代码执行与递归子 agent、共享记忆；以及为何 Claude Code / Codex / Pi 等在结构上比外表更相似；并把 harness 视为跨任务的组合泛化器。文中还提到 RLM 系 harness 曾在 ARC-AGI-3 等评测叙事中领先出现——评测成绩随版本与设置变化，本刊不把提纲中的“领先”写成当前榜首事实。

本刊关联：今天的 GPT-6 生产指南谈缓存、委托与监控；这篇访谈提醒，很多“模型做不到”的问题，可能是脚手架没有把已有能力组合起来。节目早于或并行于今日新闻，不是对今日公告的回应。Concourse ID：`kog7mwsDqnk`；核验范围为官方节目页文字，未逐字校听录音。
