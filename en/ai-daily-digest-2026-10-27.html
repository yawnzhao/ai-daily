GPT-6.1 Terra launches, stressing cost efficiency for vision and computer use

OpenAI released GPT-6.1 Terra, positioned as a fast model for visual understanding, computer use, and writing. It is open to the corresponding paid plans of ChatGPT Work and Codex, and to API developers. The published standard API price is 1 dollar per million input tokens, 0.05 dollar for cached input, and 5 dollars for output.

Official evaluations show gains on multi-step computer tasks and code tasks compared with the previous generation. Those are the vendor's results under specified tests and inference settings. They do not convert directly into savings at every company. For everyday documents, interface actions, and large amounts of repeated work, cheaper executable ability is worth watching. Harder code tasks still need a model chosen for the difficulty.

Software engineering

Microsoft on large code migrations: after generation gets faster, how to keep the old behavior

A Microsoft engineering team describes using agents for code migration, language modernization, and specification-driven development. The team says the work covers migrating compiler toolchains in large codebases and gradually moving older C and C++ code toward Rust. The bottleneck in the article is not whether a change can be generated. It is how to preserve existing behavior, safety boundaries, and architectural intent.

The method includes inducing a knowledge base from sample edits, having experts approve rules, and then letting agents generalize them; migrating by function rather than line by line; and using differential tests, held-out tests the agent has not seen, and formal specifications. The team also acknowledges that a specification derived from old code may only restate the old behavior, not how the system ought to work. Verus is part of that formal-specification context. For a company, this is an engineering method in progress, not a claim that the work is finished without human review.

SpaceX receives a binding commitment for about 40 billion dollars of GPU financing, with delivery still ahead

A statement from Apollo confirms that SpaceX has received a binding commitment for a financing lease of about 40 billion dollars covering GPUs and related equipment. The new information today is the financing structure and its conditions, not that all the compute has already been built.

AI agents start pitching editors, and newsrooms meet a new communication cost

WIRED interviewed editors and people who operate agents. The report says autonomous agents are pitching story ideas to newsrooms and seeking writing or fact-checking work. Some of the agents in the report come from iLands. Some people also run an agent podcast as a spare-time experiment. The editors interviewed generally do not accept this kind of submission. 01SWE-Shift: after the workspace changes mid-task, can a code agent still finish correctly
Code agentsAnnounced October 26; v1 submitted October 23Abstract, method, results, and limitations; not peer reviewed or independently reproduced

The SWE-Shift preprint appeared in the October 26 arXiv new-announcement list. The v1 submission date is October 23. The two dates are recorded separately. From the same intermediate execution state, the study splits two paths: one keeps the environment, the other inserts a task-related change, and then compares whether the task can be finished, still-valid work kept, and the evidence updated.

The study includes 120 designed scenarios, 12 kinds of change, and 9 intervention points, and evaluates 17 code-agent systems. The authors report that every tested system had a lower success rate after a change than in the unchanged environment. Failures shown in the paper include tests passing while a collaborator's still-valid edit is deleted, or citing a check result that is already stale.

Why read it today: it adds a question to the Microsoft migration discussion. Correctness is not only one patch passing. It is staying correct after the state changes during collaboration. The limits are designed scenarios, one update per round, and model randomness that was not fully controlled. The result does not directly represent every real repository, and it does not prove that a product is unreliable in every setting. This issue read the abstract, method, results, and limitations. It is not a peer-reviewed or independently reproduced conclusion.
