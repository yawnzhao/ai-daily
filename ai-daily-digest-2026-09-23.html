降价写进价目表之后，下一件被产品化的是「变更出去谁看着」

Sol 与 Luna 的 50% 不是转述。价目表、AutomationBench 的 33.2% 与 0.27 美元、以及「回退约占 40% 且未计入成本」都在打开的 OpenAI 页面上。前一天 Opus 5.5 用「低 40%」描述运行成本，这一窗口里 OpenAI 把降价写成输入和输出的美元价格。

Cursor 的两个机器人不提高榜单分数。Rollouts 在部署后按环境给健康结论，Security Review 在 PR 上报告可利用缺陷。页面写明 Rollouts 不合并、不直接部署。

  • 价格：Sol 2/10 美元，Luna 0.10/0.50 美元，每百万 token。
  • 对照：官方表把 Sol 和 Opus 5、Fable 5.1 放在同一张 AutomationBench 上。
  • 发布后：Cursor 把监视和审查做成 Teams / Enterprise 功能。
一句话总结：这一窗的主线是价目表和部署监视，不是又一条模型昵称。

01推理时的能力与效率如何一起缩放
推理效率
推理模型的能力是答对，效率是用有限的 token 答对。思维链面对可控难度的题目时，答对的题数和花掉的 token 都跟题目难度、模型大小有关，但两者怎么一起变还不清楚。论文用分层贝叶斯模型，看 DeepSeek-R1-Distill 系列在四类算术和算法题上的表现。模型大小固定时，答对概率大致随题目规模指数下降。提交于 09-22。

02数证据，不要数句子：长文本价值测量的证据融合
评估长文本
用大模型从长社交媒体帖子里测量价值取向时，帖子里混着背景、引语和让步，真正表态的句子很少。直接给整篇打标签容易过度自信；把每句的预测拿来投票，又把含糊的句子和决定性的句子当成一样重要。TEF 不另外训练，按每句的信息增益给它的判断加权，不确定的句子几乎不计入总分。配套基准 MIND 有 8358 篇中英文帖子，覆盖五年公共事件和六个价值维度。提交于 09-22。

03RRSI：对智能体 harness 做带正则的递归自我改进
HF Daily Papers09-22 上榜
智能体的本事很大一部分不在冻结的模型里，而在外面的提示、控制流、工具、记忆和上下文管理，也就是 harness。自动一轮轮改这些部件，会记住训练任务：分布内涨很多，换到分布外就缩掉甚至消失。RRSI 给这种自我改进加约束：每次候选能打包的修改数量随时间收紧，并鼓励走还没探索过的改法；选择时用一个批评者挡掉只对某个基准有效的方案，再用剪枝去掉多余修改。09-22 出现在 Hugging Face 当日论文。

04OmniEdu：面向学与教的开放基础模型
HF Daily Papers09-22 上榜
面向中小学的基础模型不能只会做题，还要理解课程结构、判断学生卡在哪里，并给出合适的讲解和支架。现有教育模型常常只偏解题或只偏辅导。OmniEdu 把指令数据按四种能力来组织：学科能力、课程落地、诊断推理、教学行动与支架。清洗、改写、质量打分和多样性筛选之后，得到 69999 条例子。论文提交于 09-19，09-22 出现在 Hugging Face 当日论文。

Cursor Rollouts 与 Security Review09-23Cursor

两个机器人，当天对团队版和企业版开放。Rollouts 盯一次改动在每个环境里部署得健不健康，结论是确认健康、发现回退，或还不能判断。它先在拉取请求下写监测计划，部署之后对照日志、指标和追踪；发现问题时通知作者，可以开回滚请求，但自己不合并、也不直接部署。Security Review 则在每个拉取请求上报告可以拿来利用的缺陷。
